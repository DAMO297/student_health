# 学生账号管理功能

## 需求描述

实现管理员为学生创建和管理登录账号的功能，使学生能够通过学号登录系统并查看自己的体检记录。

## 核心功能

### 1. 账号绑定机制
- 学生账号通过 `t_user.student_id` 字段与学生档案关联
- 学生账号的用户名使用学号（`student_no`）
- 学生账号类型 `user_type = 3`

### 2. 管理员操作
- **查看账号状态**：查询学生是否已绑定账号
- **创建学生账号**：为学生创建登录账号并设置初始密码
- **重置密码**：重置已有学生账号的密码

### 3. 权限控制
- 学生登录后，系统自动根据 `student_id` 过滤数据
- 学生只能查看自己的体检记录
- 管理员可以为所有学生创建和管理账号

## 实施计划

### 后端开发
1. **数据访问层**（UserMapper）
   - 添加根据 `student_id` 查询用户的方法
   - 添加更新密码的方法

2. **业务逻辑层**（UserService）
   - 实现获取学生账号信息
   - 实现创建学生账号（带学生信息验证）
   - 实现重置学生密码

3. **控制器层**（StudentController）
   - GET `/api/students/{id}/account` - 获取账号信息
   - POST `/api/students/{id}/account` - 创建账号
   - PUT `/api/students/{id}/account/reset-password` - 重置密码

### 前端开发
1. **API 封装**（student.js）
   - 封装账号管理相关的 API 调用

2. **UI 组件**（student/Index.vue）
   - 学生列表添加"账号管理"操作按钮
   - 实现账号管理对话框
   - 显示账号信息或创建账号表单
   - 提供密码重置功能

3. **用户体验**
   - 密码最少6位限制
   - 创建/重置成功后显示密码提示
   - 错误处理和友好提示

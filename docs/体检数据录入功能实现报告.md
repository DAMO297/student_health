### 前端实现
**文件**：`ui/health_ui/vite-project/src/views/exam/Index.vue`

**代码行数**：~430 行

**使用的技术**：
- Vue 3 Composition API
- Computed 属性（BMI 计算、表单验证）
- 响应式数据绑定
- 事件处理

**关键功能**：
```javascript
// BMI 自动计算
const calculatedBMI = computed(() => {
  if (form.value.height && form.value.weight) {
    const heightInMeters = form.value.height / 100;
    const bmi = form.value.weight / (heightInMeters * heightInMeters);
    return bmi.toFixed(1);
  }
  return '-';
});

// 表单验证
const isFormValid = computed(() => {
  return form.value.batchId && form.value.studentId && 
         form.value.examTime && form.value.height && form.value.weight;
});
```

### 后端 API（已存在）

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取批次列表 | GET | `/api/exam-batches` | 获取所有体检批次 |
| 获取记录列表 | GET | `/api/exam-records` | 获取体检记录（可按批次筛选） |
| 创建记录 | POST | `/api/exam-records` | 新增体检记录 |
| 更新记录 | PUT | `/api/exam-records/{id}` | 更新体检记录 |
| 获取学生列表 | GET | `/api/students` | 获取所有学生（用于下拉选择） |

## 🔄 完整业务流程

### 医生录入体检数据流程：

```
1. 医生登录系统
   ↓
2. 进入"体检管理"页面
   ↓
3. 左侧选择体检批次（例如"2025秋季体检"）
   ↓
4. 点击"新增记录"按钮
   ↓
5. 弹窗表单打开
   ↓
6. 选择学生（下拉框搜索）
   ↓
7. 填写体检数据：
   - 身高：175cm
   - 体重：65kg
   - BMI：自动显示 21.2
   - 血压：120/80 mmHg
   - 心率：72 bpm
   - 视力：左5.0 / 右5.0
   ↓
8. 点击"提交"
   ↓
9. 后端保存数据
   ↓
10. 列表自动刷新，显示新记录
    ↓
11. 医生可点击"生成报告"
    ↓
12. 学生可查看报告
```

## 5. 功能需求——体检报告生成与管理模块

### 5.1 模块目标

基于已入库的体检记录自动生成个人体检报告，支持报告查询、历史记录管理、打印与导出（PDF/Excel），并提供综合健康评估与医师建议输出能力。

### 5.2 参与角色

- **医生**：生成/预览/修订/导出所负责范围内的报告
- **管理员**：全量管理、模板配置（可选）、归档、批量导出
- **学生**：查看/下载本人报告与历史记录

### 5.3 报告内容结构

报告建议包含以下区块：

- **A. 基础信息**
  - 学号、姓名、性别、学院、年级、班级、体检日期、报告编号
- **B. 检测指标明细**
  - 各项指标数值、单位、参考范围、是否异常（高/低/正常）
- **C. 综合健康评估**
  - 依据规则计算：BMI 分类、血压分级、视力异常提示等
- **D. 医师建议**
  - 自动建议（规则库生成）+ 医生手动补充
- **E. 结论与签名**
  - 医生签名（电子签名可选）、生成时间、版本号

### 5.4 报告生成规则（示例）

#### 5.4.1 BMI 评估（示例阈值，可配置）

| BMI 区间 | 结论 | 建议示例 |
|---|---|---|
| < 18.5 | 偏瘦 | 增加优质蛋白与力量训练，规律作息 |
| 18.5~23.9 | 正常 | 保持均衡饮食与运动 |
| 24.0~27.9 | 超重 | 控制热量摄入，增加有氧运动 |
| ≥ 28.0 | 肥胖 | 建议体重管理计划，必要时医学评估 |

#### 5.4.2 血压分级（示例阈值，可配置）

| 收缩压/舒张压 | 结论 |
|---|---|
| <120 且 <80 | 正常 |
| 120~139 或 80~89 | 偏高 |
| ≥140 或 ≥90 | 高血压风险 |

#### 5.4.3 视力提示（示例）

任一眼视力低于阈值（如 < 5.0 或 < 1.0，视制度而定）提示“视力异常，建议复查/验光”。

说明：阈值应由“指标字典/阈值配置”管理（详见 `09-数据与接口规范.md` 的字典与阈值章节）。

### 5.5 功能列表（用例）

#### 5.5.1 报告生成（医生/管理员）

- **触发方式**：
  - 自动：体检记录保存/审核通过后自动生成（可配置）
  - 手动：在体检记录详情页点击“生成报告”
  - 批量：按批次批量生成
- **前置条件**：
  - 体检记录存在，必填指标齐全（或允许缺失但需标注“缺项”）
- **输出**：
  - 报告主表 + 报告明细（或直接引用体检记录） + 评估结论 + 建议
- **幂等性**：
  - 同一学生同一批次生成报告应幂等（默认更新同一份报告版本）
  - 若记录被修改：报告状态标记为“需更新”，并触发重新生成（可配置）

#### 5.5.2 报告查询与历史记录（医生/管理员/学生）

- **列表查询条件**：
  - 学号/姓名（管理员/医生）
  - 批次、学院、年级、班级
  - 异常项（BMI异常/血压异常/视力异常等）
  - 时间范围
- **学生端**：仅可按时间、批次筛选自己的报告

#### 5.5.3 报告预览与修订（医生/管理员）

- **预览**：所见即所得（PDF 预览或 HTML 预览）
- **修订**：
  - 医生可补充“医师建议”、备注、结论说明
  - 关键指标数据不建议在报告内直接改，应回到体检记录修改（保持数据源一致）
- **版本管理（建议）**：
  - 报告版本号递增（v1, v2…）
  - 记录修订原因

#### 5.5.4 导出与打印（PDF/Excel）

- **学生端**：下载本人报告（PDF 为主，Excel 可选）
- **医生/管理员**：
  - 单份导出
  - 批量导出（按批次/筛选条件）
  - 大批量导出走异步任务，生成压缩包
- **打印**：浏览器打印样式适配 A4；页眉页脚包含报告编号/二维码（可选）

#### 5.5.5 报告归档（管理员）

体检批次结束后可执行归档：
- 归档后报告不可修改，仅可查看/导出
- 归档可触发长期存储策略（如只读存储、备份）

### 5.6 交互与样式要求

- 报告页面必须提供：
  - 关键信息摘要（是否异常、异常项数量）
  - 指标表格（含参考范围与异常标记）
  - 建议区（自动建议 + 医生建议分区）
- 异常项高亮（红/橙），并提供“异常解释”tooltip

### 5.7 验收标准（本模块）

- 同一条体检记录可稳定生成可预览的报告，字段映射正确
- PDF 导出内容与预览一致，打印排版不截断
- 学生只能访问本人报告（越权测试通过）
- 批量导出可完成，且在大数据量下不阻塞主线程（异步或分页生成）

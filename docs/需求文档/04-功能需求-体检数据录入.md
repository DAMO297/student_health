## 4. 功能需求——体检数据录入模块

### 4.1 模块目标

支持医生/管理员录入学生体检数据，提供单条录入与 Excel 批量导入，并在录入阶段完成**完整性校验、合理性校验、异常提示**，为报告生成与统计分析提供高质量数据。

### 4.2 参与角色

- **医生**：主使用者（录入、编辑、查看范围内数据）
- **管理员**：可录入与纠错、审核（若启用）
- **学生**：只读查看本人记录（可选：仅通过报告查看）

### 4.3 数据结构（体检记录）

建议采用“体检批次 + 学生 + 指标项”的结构，兼容不同年份/不同项目扩展。

#### 4.3.1 体检批次（ExamBatch）

| 字段 | 必填 | 说明 |
|---|---:|---|
| batchId | ✅ | 主键 |
| batchName | ✅ | 批次名称（如“2025年秋季体检”） |
| startDate/endDate | ✅ | 批次周期 |
| status | ✅ | 未开始/进行中/已结束/归档 |
| createdAt/createdBy | ✅ | 审计字段 |

#### 4.3.2 体检记录主表（ExamRecord）

| 字段 | 必填 | 说明 |
|---|---:|---|
| recordId | ✅ | 主键 |
| batchId | ✅ | 批次关联 |
| studentId/studentNo | ✅ | 学生关联 |
| doctorId | ✅ | 录入医生 |
| recordTime | ✅ | 体检/录入时间 |
| source | ✅ | 手工录入/批量导入 |
| auditStatus | ✅ | 待审核/已审核/驳回（可选） |
| remark | 否 | 备注 |
| createdAt/updatedAt | ✅ | 审计字段 |

#### 4.3.3 指标明细（ExamMetric）

| 指标 | 单位 | 类型 | 合理范围（示例，可配置） | 说明 |
|---|---|---|---|---|
| 身高 height | cm | 数值 | 50~250 | 可用于 BMI |
| 体重 weight | kg | 数值 | 10~300 | 可用于 BMI |
| BMI | - | 计算 | 10~60 | 系统计算，非必填 |
| 收缩压 sbp | mmHg | 数值 | 60~250 | 血压 |
| 舒张压 dbp | mmHg | 数值 | 30~150 | 血压 |
| 心率 heartRate | bpm | 数值 | 30~220 | - |
| 左眼视力 visionL | - | 数值 | 0.1~5.0 | 或按 4.0~5.3 制 |
| 右眼视力 visionR | - | 数值 | 0.1~5.0 | - |
| 血常规 wbc/rbc/hgb 等 | - | 数值 | 按项目配置 | 建议字典化 |
| 肝功能 alt/ast 等 | - | 数值 | 按项目配置 | 建议字典化 |

说明：
- 指标项建议以“指标字典 + 阈值标准”驱动，避免字段硬编码；但毕业设计也可先实现核心字段（身高体重血压心率视力）+ 扩展字段 JSON。

### 4.4 录入方式一：单条录入

#### 4.4.1 用例：创建体检记录

- **前置条件**：
  - 学生已存在
  - 批次处于“进行中”（可配置）
- **录入内容**：
  - 基础：学生、批次、体检时间、录入医生
  - 指标：身高、体重、血压、心率、视力、（扩展项）
- **自动计算**：
  - BMI：根据身高体重自动计算，保留 1 位小数（可配置）
- **校验**：
  - 必填校验（按指标配置）
  - 合理范围校验（超范围提示“疑似错误”，允许提交但需二次确认或标记异常）
  - 逻辑校验：例如 sbp 必须 ≥ dbp
  - 重复校验：同一学生同一批次是否已存在记录（可允许多次记录但需标记“复检/复测”）
- **结果**：
  - 保存成功，进入详情或返回列表
  - 若启用审核：保存后状态=待审核

#### 4.4.2 用例：编辑体检记录

- **权限**：
  - 医生：仅能编辑自己录入且未审核的记录（默认）
  - 管理员：可编辑所有记录（审计）
- **审计**：记录修改字段与原因（可选要求录入“修改原因”）

#### 4.4.3 用例：删除/撤回体检记录

建议采用逻辑删除：
- 未审核：可撤回
- 已审核：默认禁止删除，仅管理员可进行“作废/更正”（保留更正链路）

### 4.5 录入方式二：Excel 批量导入

#### 4.5.1 导入模板要求

模板列（建议最小集）：
- 学号（必填）
- 批次名称/批次ID（必填其一）
- 体检时间（必填）
- 身高、体重、收缩压、舒张压、心率、左/右眼视力（可配置必填）
- 扩展项（可选：以列形式或 JSON 文本列）

#### 4.5.2 导入流程与校验

- **流程**：上传 → 解析 → 预校验 → 错误清单 → 确认导入 → 结果报告
- **校验规则**：
  - 学号存在性校验
  - 批次存在且可导入（状态=进行中）
  - 数值字段格式/范围/逻辑（sbp≥dbp）
  - 同一学生同一批次重复：按策略处理
- **导入策略（可配置）**：
  - 跳过重复
  - 覆盖更新（仅未审核记录）
  - 追加新记录（复检）

#### 4.5.3 导入结果输出

导入完成后需返回：
- 成功条数/失败条数
- 失败明细：行号、学号、字段、原因
- 生成结果文件下载（可选）

### 4.6 数据审核（可选）

若启用审核：
- **审核人**：管理员（默认）或具备审核权限的医生
- **审核动作**：通过/驳回（需理由）
- **驳回后**：记录可编辑，重新提交审核

### 4.7 页面/交互要求

- 录入页：按“基础信息 + 指标项”分区；异常项高亮；实时计算 BMI
- 批量导入：模板下载、上传进度、错误清单可复制/下载
- 记录列表：支持按批次/学院/年级/异常项筛选；支持导出

## 9. 数据与接口规范

### 9.1 数据库与命名约定（建议）

- 表命名：`t_` 前缀（例如 `t_student`、`t_exam_record`）
- 主键：`id`（Long 自增或 UUID）
- 审计字段：`created_at/created_by/updated_at/updated_by`
- 逻辑删除：`deleted`（0/1）或 `status`

### 9.3 RESTful 接口规范

#### 9.3.1 通用约定

- Base Path：`/api`
- 编码：UTF-8
- 数据格式：JSON
- 分页参数：
  - `page`（从 1 开始）
  - `pageSize`
  - `sortBy`、`sortOrder=asc|desc`
- 统一响应结构（建议）：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "..."
}
```

- 统一错误码（建议）：
  - `0`：成功
  - `40001`：参数校验失败
  - `40101`：未登录/Token 失效
  - `40301`：无权限
  - `40401`：资源不存在
  - `40901`：冲突（如学号重复）
  - `50000`：系统异常

#### 9.3.2 认证接口

- `POST /api/auth/login`
  - 入参：username、password、captcha（可选）
  - 出参：accessToken、expiresIn、userInfo

- `POST /api/auth/logout`（可选）
  - 说明：服务端可写入 Redis 黑名单或提升 tokenVersion

#### 9.3.3 学生管理

- `GET /api/students`
  - 查询：studentNo、name、college、grade、clazz、status、page/pageSize
- `POST /api/students`
- `GET /api/students/{id}`
- `PUT /api/students/{id}`
- `DELETE /api/students/{id}`（逻辑删除）
- `POST /api/students/import`
  - `multipart/form-data` 上传 Excel
- `GET /api/students/template`
  - 下载导入模板
- `GET /api/students/export`
  - 导出 Excel（可同步/异步）

#### 9.3.4 体检批次与记录

- `GET /api/exam-batches`
- `POST /api/exam-batches`
- `PUT /api/exam-batches/{id}`
- `POST /api/exam-records`
- `PUT /api/exam-records/{id}`
- `GET /api/exam-records`
  - 查询：batchId、studentNo、college、grade、abnormalFlag、timeRange
- `POST /api/exam-records/import`
- `GET /api/exam-records/export`

#### 9.3.5 报告

- `POST /api/reports/generate`
  - 入参：recordId 或（batchId + filters）
- `GET /api/reports`
- `GET /api/reports/{id}`
- `PUT /api/reports/{id}`（仅建议/备注等）
- `GET /api/reports/{id}/export/pdf`
- `GET /api/reports/{id}/export/excel`
- `GET /api/reports/export`（批量）

#### 9.3.6 统计分析

- `GET /api/analytics/overview`
  - 返回：关键指标卡片（总人数、异常率等）
- `GET /api/analytics/distribution`
  - 入参：dimension=college|grade|gender，metric=bmi|bp|vision，batchId
- `GET /api/analytics/trend`
  - 入参：metric、groupBy、timeRange
- `POST /api/analytics/cluster`（可选）
- `POST /api/analytics/regression`（可选）

#### 9.3.7 任务调度与仪表盘

- `GET /api/dashboard/metrics`
- `GET /api/scheduler/jobs`
- `PUT /api/scheduler/jobs/{id}`
- `POST /api/scheduler/jobs/{id}/trigger`

### 9.4 JWT 传递规范

- Header：`Authorization: Bearer <token>`
- Token 过期时间：例如 2 小时（可配置）
- 续期策略：可选 Refresh Token

### 9.5 文件上传下载规范

- 上传大小限制：建议默认 10MB（可配置）
- 支持格式：`.xlsx`（导入）；导出 `.xlsx`/`.pdf`
- 下载安全：鉴权 + 审计记录 + 防目录遍历

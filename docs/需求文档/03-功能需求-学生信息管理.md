## 3. 功能需求——学生信息管理模块

### 3.1 模块目标

维护学生基础档案，提供可靠的唯一标识、数据一致性与可追溯变更能力，为体检录入、报告生成、统计分析提供主数据支撑。

### 3.2 参与角色

- **管理员**：新增/修改/删除/批量导入/导出、数据纠错、字段配置（可选）
- **医生**：只读查询（受数据范围策略限制）
- **学生**：查看本人信息；可选允许维护部分字段（如手机号、邮箱、紧急联系人）

### 3.3 数据字段要求（学生主档）

| 字段 | 类型 | 必填 | 规则/校验 | 说明 |
|---|---|---:|---|---|
| id | Long/UUID | ✅ | 系统生成 | 主键 |
| studentNo（学号） | String | ✅ | **唯一**；长度 4~20；仅字母数字-下划线 | 业务唯一键 |
| name（姓名） | String | ✅ | 1~50 字符 | - |
| gender（性别） | Enum | ✅ | 男/女/未知 | - |
| college（学院） | String | ✅ | 1~100 | 支持字典 |
| grade（年级） | String/Int | ✅ | 合法年级（如 2022） | - |
| clazz（班级） | String | ✅ | 1~100 | - |
| idCard（身份证） | String | 否 | 18 位校验（可选） | 敏感字段 |
| phone（手机号） | String | 否 | 正则校验 | 可由学生维护（可选） |
| email | String | 否 | 邮箱格式 | 可由学生维护（可选） |
| birthday | Date | 否 | 合法日期 | - |
| status（状态） | Enum | ✅ | 正常/冻结/毕业/删除 | 逻辑删除建议 |
| createdAt/updatedAt | DateTime | ✅ | 自动维护 | 审计字段 |
| createdBy/updatedBy | String/Long | ✅ | 自动维护 | 审计字段 |

一致性约束：
- 学号全局唯一
- 学号与姓名组合不作为唯一约束（避免重名问题）
- 删除建议采用**逻辑删除**（status=删除），保留历史体检数据的可追溯性

### 3.4 功能列表（按用例）

#### 3.4.1 学生列表查询（管理员/医生）

- **入口**：学生管理 → 列表
- **查询条件**：
  - 学号/姓名（模糊）
  - 学院、年级、班级（下拉/联动）
  - 状态（正常/冻结/毕业/删除）
  - 创建时间范围（可选）
- **返回字段**：列表展示字段可配置；默认包含 学号、姓名、性别、学院、年级、班级、状态、更新时间
- **分页**：必须支持分页与排序（默认按更新时间倒序）
- **权限**：
  - 管理员：全量
  - 医生：按数据范围策略过滤

验收点：
- 查询 10 万级数据仍可分页响应（具体性能指标见非功能需求）

#### 3.4.2 新增学生（管理员）

- **表单字段**：学号、姓名、性别、学院、年级、班级（必填）；其余可选
- **校验**：
  - 学号唯一校验（前端提示 + 后端强校验）
  - 必填项非空
  - 学院/年级/班级在字典配置范围内（若启用字典）
- **结果**：创建成功后可进入详情页
- **审计**：记录创建人、时间、字段变更

#### 3.4.3 编辑学生（管理员；学生可选）

管理员可编辑全字段（敏感字段需权限点控制），学生仅能编辑开放字段（如手机号/邮箱）。

- **并发控制**：建议支持乐观锁（version 字段）或更新时间校验，防止覆盖
- **审计**：记录变更前后差异（建议 JSON diff）

#### 3.4.4 删除学生（管理员）

建议仅支持**逻辑删除**：
- 若存在体检记录/报告：禁止物理删除；可标记删除/毕业
- 若无任何关联数据：允许管理员物理删除（可选）

#### 3.4.5 批量导入学生（管理员）

导入方式：Excel（`.xlsx`）

- **流程**：
  - 下载模板 → 上传文件 → 解析 → 预校验 → 返回错误清单/成功预览 → 确认导入 → 入库
- **校验规则**：
  - 必填列存在且值非空
  - 学号重复（文件内/与库内）
  - 枚举字段合法性（性别、状态等）
  - 字典字段合法性（学院/班级等，若启用）
- **导入策略**（可配置）：
  - 追加：跳过已存在学号
  - 覆盖：已存在学号执行更新（需二次确认）
  - 失败回滚：任一行失败则整体回滚（默认建议关闭，改为“部分成功+错误清单”）
- **输出**：生成导入结果报告（成功数/失败数/失败原因/行号），支持下载

#### 3.4.6 导出学生（管理员）

支持导出 Excel：
- 可导出当前查询条件下结果
- 可选择字段
- 大数据量导出建议走异步任务（生成后通知下载）

### 3.5 页面/交互要求（前端）

- 列表页：筛选区 + 表格 + 分页；支持勾选批量操作（导出/删除/状态变更）
- 新增/编辑：抽屉或弹窗表单，提交前校验提示
- 导入：上传组件 + 模板下载 + 进度提示 + 错误清单表格

### 3.6 错误提示与异常处理（用户可理解）

错误提示需满足：
- 明确指出字段与原因（如“第 12 行：学号已存在：20220101”）
- 同类错误可聚合统计（如“学号重复 5 条”）
- 系统异常不暴露堆栈，统一返回可读错误码与提示（见 `09-数据与接口规范.md`）

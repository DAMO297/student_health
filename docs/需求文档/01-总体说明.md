## 1. 项目总体说明

### 1.1 项目名称

学生健康体检管理系统（学生健康体检报告管理系统）。

### 1.2 建设背景与目标

- **背景**：学校体检数据分散、录入效率低、报告管理不统一、统计分析困难、权限与审计不足。
- **目标**：构建一套基于 Spring Boot + Vue.js 的模块化体检管理系统，实现体检数据全流程（学生信息→录入→报告→统计分析→权限安全→运维调度）闭环管理，并具备导入导出、审计追踪与可视化能力。

### 1.3 系统边界（In Scope / Out of Scope）

- **In Scope（本课题范围内）**
  - 学生信息管理（含批量导入）
  - 体检数据录入（单条/批量）
  - 体检报告生成、查询、导出、打印
  - 健康数据统计分析与可视化（ECharts 或 Superset）
  - 权限认证授权（Spring Security + JWT），三类角色（管理员/医生/学生）
  - 传输安全（AES 加密）、缓存（Redis）、定时任务（Quartz）
  - 日志/审计、系统状态仪表盘（访问量、更新频率等）

- **Out of Scope（不在本课题范围/可选拓展）**
  - 与第三方体检设备或医院 HIS 的深度对接（如设备直连采集）
  - 医疗影像存储、PACS 集成
  - 移动端原生 App（可用 H5 适配代替）
  - 复杂的医保/费用结算链路

### 1.4 用户角色与使用场景概述

- **管理员**
  - 管理学生与用户账号、角色权限
  - 审核体检数据/报告（如启用审核流程）
  - 配置系统参数、体检项目字典、指标阈值标准
  - 运维：任务调度、日志审计、数据归档/导出

- **医生**
  - 录入体检数据（单条/批量）
  - 校验与修订体检项
  - 生成/预览/补录体检报告

- **学生**
  - 注册/登录
  - 查看个人信息、维护部分资料（可配置开放字段）
  - 查看/下载个人体检报告与历史记录
  - 指标对比、健康提示与预警

### 1.5 业务流程概览（文字版）

- **主流程**：
  - 管理员维护学生基础信息 → 医生录入体检数据（校验） → 系统自动生成体检报告 → 学生查看/下载 → 管理员统计分析与决策支持

- **批量导入流程**：
  - 下载模板 → 填写 Excel → 上传 → 系统预校验（格式/必填/范围）→ 预览错误清单 → 确认入库 → 生成导入结果报告

### 1.7 术语与缩略语

- **BMI**：身体质量指数，\( BMI = \frac{体重(kg)}{身高(m)^2} \)
- **JWT**：JSON Web Token，用于无状态认证
- **RBAC**：基于角色的访问控制
- **ECharts**：前端可视化图表库
- **Superset**：BI 可视化分析平台（可选）
- **AES**：高级加密标准，对称加密算法
- **Quartz**：Java 定时任务调度框架

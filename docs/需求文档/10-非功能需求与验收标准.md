## 10. 非功能需求与验收标准

### 10.1 性能需求

- **响应时间**
  - 常规查询接口：平均 < 300ms（开发环境除外）
  - 列表分页：平均 < 500ms
  - 报告生成：单份 < 2s；批量生成按分页/异步执行
- **并发能力（目标值，可在答辩中说明为“可扩展”）**
  - 同时在线用户：100（示例）
  - 峰值 QPS：50（示例）
- **数据库**
  - 常用查询必须有索引（studentNo、batchId、recordTime、college/grade/gender）
- **缓存**
  - 字典/阈值/热点学生信息使用 Redis 缓存

### 10.2 安全需求

- **认证授权**：Spring Security + JWT，RBAC + 数据范围
- **敏感信息保护**：
  - 密码必须使用 BCrypt 哈希存储
  - 日志脱敏（身份证、手机号、健康指标可按策略脱敏）
  - 导出文件需权限校验并记录审计
- **传输安全**：
  - 生产环境启用 HTTPS
  - AES 加密策略按 `07-功能需求-系统权限与安全管理.md` 执行
- **防攻击**
  - 登录失败限制
  - CORS 白名单
  - 文件上传类型与大小校验

### 10.3 可靠性与可用性

- **容错**：批量导入部分失败可返回错误清单，不影响成功数据入库（默认策略）
- **幂等**：报告生成、任务调度触发需幂等
- **数据备份（可选）**：提供备份策略说明（手动/定时）

### 10.4 可维护性与可扩展性

- 后端分层：Controller/Service/DAO（Mapper）
- 模块化：学生、体检记录、报告、统计、权限、调度
- 指标字典化：体检指标与阈值尽量配置化（便于扩展）

### 10.5 可用性（UX）要求

- 表单校验即时反馈，错误信息可理解（行号、字段、原因）
- 异常项高亮（体检录入与报告页）
- 导入导出必须有进度/结果提示

### 10.6 日志与审计

- 业务操作审计（详见权限模块）
- 错误日志：记录 traceId，便于定位
- 定时任务执行日志：成功/失败原因、耗时、影响数据量

### 10.7 验收测试清单（系统级）

#### 10.7.1 功能验收（抽样）

- 学生信息新增/编辑/删除/导入/导出可用
- 体检记录单条录入与批量导入可用，范围/逻辑校验生效
- 报告可生成、可预览、可导出 PDF/Excel、学生仅可访问本人
- 统计分析至少实现 4 类图表并支持筛选联动
- 管理员可管理任务调度并查看任务日志

#### 10.7.2 权限与越权测试

- 学生访问他人报告接口返回 403
- 医生访问范围外学生记录返回 403
- 无 Token 访问受保护接口返回 401

#### 10.7.3 安全与稳定性

- 上传非法文件类型被拒绝
- 登录失败次数达到阈值触发限制
- 系统异常返回统一错误结构，不暴露堆栈

## 数据库设计说明（用于导入）

### 1. 默认数据库选型

本项目当前仓库未锁定数据库依赖（`pom.xml` 为空依赖），为便于你直接导入使用，本脚本默认提供：

- **MySQL 8.0+**
- 字符集：`utf8mb4`
- 存储引擎：`InnoDB`

文件说明：

- `schema-mysql.sql`：建库、建表、索引、外键、注释（可直接导入）
- `seed-mysql.sql`：初始化数据（角色/权限/示例指标字典/默认账号占位）

### 2. 设计原则（与开题报告一致）

- **模块覆盖**：学生信息、体检数据录入、报告、统计分析（数据基础）、权限安全、审计、任务调度
- **审计与追溯**：所有核心业务表包含 `created_at/created_by/updated_at/updated_by`
- **逻辑删除**：核心表包含 `deleted`（0/1），避免历史数据丢失
- **扩展性**：体检指标采用 `t_exam_metric`（记录-指标明细）+ `t_metric_dict`（指标字典）方式，避免字段硬编码

### 3. 导入方法（推荐顺序）

1) 先导入建表脚本：

- 执行 `docs/数据库/schema-mysql.sql`

2) 再导入初始化数据：

- 执行 `docs/数据库/seed-mysql.sql`

### 4. 注意事项

- `t_user.password_hash` 需要使用 **BCrypt** 存储；初始化脚本中提供的是“占位 hash”，建议你后续在系统里通过“重置密码/初始化管理员”功能生成真实 hash。
- Quartz 若使用官方持久化表（`QRTZ_` 前缀），建议使用 Quartz 官方提供的 MySQL 建表脚本；本次先按“简化任务表 + 任务日志表”满足开题报告需求。

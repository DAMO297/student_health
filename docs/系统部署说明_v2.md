# 学生健康管理系统 - 部署说明文档 (V2)

## 1. 环境依赖
- **JDK**: 1.8+
- **Maven**: 3.6+
- **MySQL**: 5.7+
- **Redis**: 5.0+

## 2. 数据库更新
系统新增了部分功能（审计、定时任务），需要执行额外 SQL 脚本以创建必要的数据表。
请按顺序在数据库中执行以下脚本：

### 2.1 基础数据
（如果尚未初始化数据库，请先执行原有的 database SQL）

### 2.2 新增模块 SQL
请务必执行以下两个脚本：
1. **审计日志表**: `src/main/resources/sql/audit_log.sql`
   - 创建 `t_audit_log` 表，用于记录系统操作日志。
2. **定时任务表**: `src/main/resources/sql/scheduler_job.sql`
   - 创建 `t_scheduler_job` 表，用于存储定时任务配置。

## 3. 配置文件
请检查 `src/main/resources/application.yml`，确保以下配置正确：
- **MySQL**: URL, Username, Password.
- **Redis**: Host, Port, Password.

## 4. 启动项目
在项目根目录下执行：
```bash
mvn spring-boot:run
```

## 5. 验证部署
项目启动成功后（看到 `Started Main in ...` 日志），可以尝试访问：
- **API 文档 (如有 Swagger)**: `http://localhost:8080/doc.html` (假设)
- **测试接口**: 
    - 登录: `POST /api/auth/login`
    - 导出学生: `GET /api/students/export`

## 6. 常见问题
- **启动报错 `Table 'xxx.t_audit_log' doesn't exist`**: 
  - 原因：未执行 2.2 中的 SQL 脚本。
  - 解决：请执行 `audit_log.sql` 和 `scheduler_job.sql`。
